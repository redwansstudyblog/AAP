# AI Site Access — কাকে দেবেন

এই প্যাকেজটা দেবেন **যে AI দিয়ে আপনি কোনো লগইন-প্রোটেক্টেড ওয়েবসাইটে কাজ করাতে চান**, সেই AI-কে (এজেন্সির কোনো প্রজেক্টে, বা যেকোনো ক্লায়েন্ট সাইট রিভিউ/টেস্ট করার কাজে)।

## এতে কী আছে
- `SKILL.md` — AI-এর জন্য পুরো নির্দেশনা, তিনটা ধাপে সাজানো (AAP → ব্রাউজার টুল → স্ক্রিপ্ট)
- `scripts/login.js` — যদি টার্গেট সাইট এখনো AAP সাপোর্ট না করে, তাহলে ফলব্যাক হিসেবে ব্যবহার হবে
- `package.json` — `login.js`-এর ডিপেন্ডেন্সি

## কীভাবে ব্যবহার করবেন
1. এই প্যাকেজটা AI-এর (Claude Code বা অনুরূপ কোনো এজেন্ট) প্রজেক্ট ফোল্ডারে/skills-এ রাখুন
2. AI-কে শুধু বলুন: "এই সাইটে ঢুকে [যা করতে চান] করো" — URL দিয়ে
3. AI নিজে থেকেই:
   - প্রথমে চেক করবে সাইটে AAP (`/.well-known/ai-access.json`) আছে কিনা — থাকলে আপনার কাছে শুধু একটা API key চাইবে
   - না থাকলে ব্রাউজার টুল থাকলে সেটা দিয়ে, নাহলে `login.js` রান করে সাইটে ঢোকার চেষ্টা করবে, আপনার কাছে ওই নির্দিষ্ট সাইটের username/password চেয়ে নেবে

## মনে রাখবেন
- এটা শুধু সেই সাইটগুলোতে ব্যবহার করুন যেগুলোতে অ্যাক্সেসের অনুমতি আপনার আছে (নিজের সাইট, বা ক্লায়েন্টের অনুমতি নিয়ে)
- একই credential একাধিক সাইটে কখনো ব্যবহার হবে না — এটা স্কিলের মধ্যেই নিষিদ্ধ করা আছে
